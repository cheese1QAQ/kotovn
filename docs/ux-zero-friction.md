# 用户无感（Zero-Friction）图形界面交互规范（目标 #6）

> **设计信条**：好的游戏翻译器在正常游玩时应当**像游戏原生字幕一样隐形**——不需要用户先学 20 个参数、不需要每次启动重新画框、不需要切出游戏去管数据库。

---

## 1. 技术栈选型：Tauri v2 (React + TypeScript) + Python Sidecar

选择 **Tauri v2 + Python 本地引擎** 的核心原因：
1. **原生无感窗口能力**：Tauri/Rust 直接提供无边框透明窗口、系统级置顶（Always-on-Top）、鼠标事件穿透（Click-Through）、系统托盘（System Tray）与全局热键，且安装包体积极小，不吃后台内存。
2. **前后端边界清晰**：AI 推理、视觉模块、RAG 与轻量化研究全部保留在纯 Python (`backend/`)，前端只负责轻量渲染与交互（`desktop/`），通过本地 `FastAPI + WebSocket` 解耦。
3. **跨平台工程化与 CD**：支持后续在 GitHub Actions 上自动化打包 Windows / Linux 发行版。

---

## 2. 极简两步冷启动（唯一需要用户操作的流程）

首次启动应用，用户只需完成两步即可开始游戏：

1. **Step 1：模型与算力预设（一键自动检测）**
   - 应用启动时自动探测 CPU 线程数与可用显存（如检测到 12GB GPU + 16 线程 CPU），直接推荐并高亮最稳妥的档位（默认 **纯 CPU 静音省显存模式**，可一键切换 **12GB 混合加速模式**）。
   - 用户选择或一键下载一个推荐的轻量化 GGUF 模型（如 4B CPU 档或 7B 混合档），无需手动填 `n_ctx`、`n_gpu_layers` 等专业参数（专业参数折叠在“开发者/研究模式”下）。
2. **Step 2：选择游戏窗口**
   - 展示当前正在运行的应用窗口缩略图列表，点击目标视觉小说窗口即可附着（Attach）。
   - 附着后主窗口自动收起到系统托盘，直接进入游戏悬浮字幕状态。

---

## 3. 日常游玩无感体验设计（Overlay HUD）

| 交互场景 | 无感自动化设计 | 可选微调入口（不打扰默认流程） |
| :--- | :--- | :--- |
| **对话框定位** | 自动侦测游戏画面底部文本密集区（Auto-ROI）与角色名区域，无需手动拉框 | 按 `Alt+R` 可临时手动重选区域并按游戏自动记忆 |
| **窗口跟随** | 自动监听游戏窗口位置、缩放与焦点变化；游戏切后台/最小化时悬浮窗自动隐藏 | 拖动悬浮字幕条可自由微调停靠位置 |
| **鼠标操作** | 悬浮字幕默认 **完全鼠标穿透（Click-Through）**，绝不遮挡玩家点击游戏继续对话 | 仅当鼠标悬停在“微弱拖拽角标”或按住修饰键时恢复交互 |
| **流式出字** | 翻译结果按 Token 流式渲染，与原版 VN 节奏一致，降低等待感 | 可调字体大小与半透明毛玻璃背景 |
| **边翻边学纠错** | 命中 RAG 术语的词汇在译文中显示极细微的虚线下划线；新学草稿词仅轻微提示 | 悬停词条浮现小卡片：可查看解释或**原位改译名 -> 回车立即锁定 `verified`** |
| **快速热键** | `Alt+T` 显隐字幕、`Alt+E` 重译当前句、`Alt+H` 展开历史与控制台抽屉 | 支持在设置抽屉中自定义 |

## 4. 进阶控制台抽屉（Studio Drawer — 面向开发者与重度玩家）

平时完全隐藏，仅通过托盘或热键 `Alt+H` 呼出，服务于你的学习与调优需求：
1. **RAG 知识库面板**：浏览当前游戏的术语表（按 `draft`/`verified` 筛选）、人物关系列表，支持一键创建/回滚 **分支 Checkpoint 快照**。
2. **人格工坊（Persona Studio）**：查看各角色已匹配的人格模板与语言指纹；内置**实时试译对比框**（输入同一句原文，并排对比不同人格范本的译文差异）。
3. **轻量化性能监视器**：以简洁折线/条形图展示实时 `TTFT`、`tok/s`、`Vision 耗时`、`RAG 耗时` 以及 CPU/VRAM 占用，直观验证不同量化模型的实际体感差距。
